# SnapConvert
Free in-browser file converter (English, global). Zero-dependency Node build (`node build.mjs`), ffmpeg.wasm vendored in `src/public/vendor/ffmpeg` (do not fetch from CDN — worker must be same-origin). Contact email must be 1122yukh@gmail.com. Headless Chromium for tests: `~/pw` (playwright). See README.md.
